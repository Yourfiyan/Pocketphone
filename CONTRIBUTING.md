# Contributing to PocketPhone

Thanks for your interest in contributing!

## Getting Started

1. **Fork** and **clone** the repository
2. **Set up a local PHP environment** (XAMPP, MAMP, or PHP built-in server):
   ```bash
   php -S localhost:8000
   ```
3. **Create a MySQL database** and update credentials in `admin/db_config.php`
4. **Open the project** in your browser

## Guidelines

- Follow existing code style
- Test all CRUD operations after making changes
- Do not commit database credentials or `.env` files
- Validate all user input server-side
- Update README if your changes add new features

## Bug Reports

Open an issue with steps to reproduce, expected vs actual behavior.
